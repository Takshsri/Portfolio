## ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/Takshsri/Portfolio.git
```

Navigate into project:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

## 🏗️ Build For Production

```bash
npm run build
```
